# Caption 分簇与压缩视觉更新

这是一个小领域的离线动态加入实验：**文本表征决定分组，视觉表征只随成员变化更新**。目前已补充独立的在线单题打分实验，尚未接入统一 QA pipeline，也不预先保证语义分组或 QA 性能。

## 保存什么

| 对象 | 持久状态 |
|---|---|
| 叶子 | ID、完整 caption、对话、时间戳、所属 master、两个视觉坐标 |
| master | 成员 ID、成员数、完整视觉向量和、近似标记、来源簇重叠记录 |
| 独立 sidecar | master 的视觉向量和、固定共享二维基底；均值引用同一行并除以成员数 |
| 可重建文本缓存 | 每条 caption 的文本 embedding；本次只缓存在运行内存，不写入结果目录 |

核心不保存旧原图、图片路径或旧图片的完整视觉 embedding。新图的完整视觉向量只在当前加入过程中使用。图 JSON 引用 sidecar，不内联完整视觉向量。

本次误差评估使用历史两两视觉相似度构成的 Gram 矩阵，以及独立评估器维护的残差混合系数。评估不保存单图完整视觉向量，也不重编码旧 Home 图片；Gram 和混合系数不输入记忆更新过程，不属于部署记忆状态。原始数据集只是逐条输入来源，不复制到新记忆目录，也不删除研究数据集。

## 一次加入的流程

1. 新图取得完整 caption、生成文本 embedding 和临时视觉 embedding；两种 embedding 分别做 L2 归一化。本次复用此前 190 分实验中的原始完整 caption，不重新生成 caption，耗时统计也不包含 caption 生成。
2. 只收集截至当前已到达的 caption 向量，使用欧氏距离做 Ward 层次聚类。
3. 回放 Ward 的合并记录，得到精确的候选簇数，计算各分组的平均欧氏轮廓系数并选择最高分。分数相差不超过 `1e-12` 时选择较少簇；该容差仅处理数值平分，不是相似度加入阈值。
4. 对比新旧成员集合。完全不变的簇保留 master ID 和原视觉统计量；发生变化的簇新建 ID，记录旧 master 到新 master 的重叠成员和人数。
5. 从同一个旧状态快照，同时计算所有新 master 的视觉统计量，最后一次性提交，避免迁移顺序影响结果。

候选范围与边界是明确的方法假设：

- `N=1` 或 `N=2`：保持单例。
- `N>=3` 且归一化文本向量全部逐值完全相同：作为退化情况合为一簇。
- 其余情况只比较 `2 <= K <= N-1`。轮廓系数不能评价一般的“全部一簇”或“全部单例”，因此本方法不会在这些一般情况选择两个端点。
- 对等高合并直接回放树的合并记录，而非按距离切割，避免跳过某些候选 K。

## 固定共享二维空间

先在独立的外域校准数据上，对视觉向量做中心化 PCA/SVD，取前两个正交方向组成 `U`，形状为 `D × 2`。校准数据不包含被测领域的未来图片。整个动态实验中固定 `U`，不重新拟合。

归一化新图向量为 `v_i`，叶子保存**绝对投影**：

```text
z_i = Uᵀ v_i
```

这里不减当前簇中心，也不减校准均值。校准均值只用于拟合 PCA 方向；叶子坐标都处于同一个固定空间。两个坐标通常不能恢复完整向量。

## 视觉统计量如何随重分组更新

旧簇 `C` 保存完整向量和 `S_C`、成员数 `n_C` 和成员坐标。它在二维空间之外尚未细分到成员的聚合残差为：

```text
R_C = S_C − U Σ(i∈C) z_i
```

设新簇为 `D`，其中旧成员与旧簇 `C` 的交集为 `C ∩ D`，本次新图完整向量仍然可用。新向量和为：

```text
S_D = U Σ(i∈D的旧成员) z_i
      + Σ(旧簇C) [ |C∩D| / n_C ] R_C
      + Σ(i∈D的本次新图) v_i

visual_mean_D = S_D / |D|
```

向量和与均值均不再次归一化。所有旧残差都来自同一快照。

- **追加新图、完整簇合并**：相对已有统计量可精确更新。
- **拆分旧簇、迁移部分旧成员**：保留成员在二维空间的投影，将不可恢复的其余残差按人数分配，属于近似。
- 经历部分重分配的 master 标记为近似；后续追加或合并不会清除该标记。
- 全库向量和守恒，且每个 master 满足 `Uᵀ S_C = Σ z_i`，误差只应来自浮点运算。这些性质不代表每个簇的完整中心仍等于真实中心。

## 这版实验能检查什么

重点检查每步簇数和单例比例、成员变化、更新耗时、视觉均值近似误差，以及状态是否遵守存储约束。没有语义标注或下游 QA 实验时，不把轮廓系数提高解释为语义更准确，也不把视觉守恒解释为细节或回答性能得到保证。

每次加入都对当前前缀**全量重建 Ward 树并枚举候选分组**。这是小领域的参考实现，用于先观察分组与近似更新行为；它不是大规模高效增量聚类算法。局部子树更新、在线检索和 QA 效果属于后续独立验证。

## 在线单题：master 定位与叶子“对话 + 完整 caption”均值

入口是 `scripts/analysis/probe_caption_visual_online.py`，首题采用 Home Q10：

> In the workspace layout test image, which desk already has a monitor on it?

1. 从冻结的 memory 读取实际保存的视觉均值 `S_C/n_C`，包含动态拆分产生的近似；不替换为评估器的真实中心。
2. 用与视觉中心同一 checkpoint 的 CLIP 文本塔和训练好的投影编码原始问题。分别归一化问题向量与中心，计算余弦，降序排列全部 master；同分保持原顺序。
3. 使用 BGE-small-en-v1.5 编码问题和所有叶子的**原始对话 + 完整 caption**。每个叶子按 `dialogue + "\nMemory description: " + caption` 拼接，包含原有 User/Assistant 两方文本，然后整体编码。只有 BGE 问题添加既有查询前缀 `Represent this sentence for searching relevant passages: `；叶子文本和 CLIP 问题均不加查询前缀。
4. 对每个簇，计算问题与每个叶子上述组合文本的余弦，再对**全部成员**取算术平均。文本编码一次批量完成，逐簇计算均值时保持第一阶段顺序。不能先归一化簇的平均文本向量再打分，这与成员相似度均值不同。

两阶段分数分别报告，不融合、不根据第二阶段分数重排，也不设阈值、选 TopK 或提前停止。历史图片、时间戳、选项、答案均不进入这次编码；原始对话作为叶子文本的一部分参与 BGE 编码。文件名和 gold 标记只在完成打分后用于检查。未调用回答模型，所以结果不代表答题正确率。叶子二维坐标本次无需参与在线打分。离线分簇仍使用 caption，增加对话只影响在线叶子检索文本。

## 未访问簇的文本相似度上界

`scripts/graph/text_similarity_bounds.py` 提供独立的、可由保存文本重建的文本索引。输入为每个叶子的“原始对话 + 完整 caption”BGE 单位向量及当前成员分组，拟合过程不使用问题、目标标签或 query–leaf 分数。视觉 master 与原 graph 均不修改。

设簇内单位文本向量为 `x_i`，单位问题向量为 `q`：

```text
c = mean(x_i)                  # 未归一化的文本均值
u = c / ||c||                  # 簇的文本方向
a = min_i dot(u, x_i)          # 最远成员决定的覆盖范围
rho = acos(a)
theta = acos(dot(q, u))
U(q, C) = cos(max(0, theta - rho))
```

该球面区域包含簇内所有文本向量，故每个成员满足 `dot(q, x_i) <= U(q, C)`。边界覆盖的是“区域内任何可能的向量”，不要求最高分方向对应真实成员，因此界可能偏宽。这个几何剪枝思路与 [Ball Tree 的中心和覆盖半径界](https://scikit-learn.org/stable/modules/neighbors.html#ball-tree)相近。

数值实现对角度和结果做由 float64 精度与维数决定的保守扩张；这是固定的舍入保护，不是可调相似度门限。零或近零均值保守退回 `U=1`；单例采用点积加舍入保护。同簇文本均值分数也可直接通过 `dot(q, c)` 得到，不能再把 `c` 归一化后当作成员分数均值。

```python
from scripts.graph.text_similarity_bounds import TextBoundIndex

index = TextBoundIndex.fit(text_vectors, member_index_groups)
upper_bounds = index.upper_bounds(query_vector)
mean_scores = index.mean_scores(query_vector)
```

索引只保留簇级中心、方向、最小余弦、半径和人数，不保存叶子向量。成员、对话、caption 或编码器改变时，必须重建受影响的索引，不能继续使用旧界。当前实现是独立实验入口，尚未接入生产 pipeline 的缓存失效逻辑。

动态搜索位于 `scripts/analysis/evaluate_text_similarity_bounds.py`。先保持 CLIP 的簇访问顺序，访问当前簇时才通过 callback 取得其叶子 BGE 分数。假设最终保留 `L` 条证据，已得到至少 `L` 条后，第 `L` 名分数作为当前比较基准：

- 当前簇的上界严格低于该分数：跳过当前簇。
- **所有剩余簇**的上界都严格低于该分数：停止。
- 其余情况继续访问；等分继续，以保留全库稳定排序的结果。

这保证与完整扫描的 BGE Top-L 一致，不保证目标记忆召回或回答充分性。最终证据数量 `L` 与访问簇数是不同概念，当前没有指定正式默认值；实验仅检查 `L=1..10`，其中 `L=5` 延续前一轮诊断。

结果位于 `reports/home_text_similarity_bounds_20261020`。52 题 × 25 簇共 1,300 次界检查，没有低于实际最高相似度的情况；52 题 × 10 个证据预算共 520 次动态搜索，全部与完整扫描 Top-L 相同。问题向量、索引状态和事后分数矩阵用于独立复核；单图视觉向量和叶子文本向量均未保存。

但本版效率有限：51 道新题、`L=5` 时平均访问 **21.43/25 簇、85.43/89 叶**，叶子打分量仅减少约 **4.0%**。另需 25 次文本方向点积来求界，合计约 **110.43** 次向量点积，高于全库直接打分的 89 次；并未获得效率收益。球面帽界比简单的 `q·c + radius` 更紧，但平均仍高出簇内真实最高分约 0.221。`report.html` 展示逐题各簇的上界、实际最高分及跳过/停止轨迹。

核心上界与动态控制流共 14 项单元测试通过，覆盖边界、随机包含性、退化向量、状态恢复、低分簇后仍有高分簇、等分排序及未满证据数不能停止。
